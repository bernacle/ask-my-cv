# Bruno Simplicio Bio

Bruno Simplicio is a Senior Software Engineer based in Dourados, Brazil.

He has 11 years of experience building product and platform systems across fintech, cloud infrastructure, and developer-facing software.

His background includes Go, TypeScript, PostgreSQL, Kubernetes, Temporal, distributed systems, identity, end-to-end product delivery, Open Finance, and crypto compliance.

He currently works at Nirvana Labs, building backend and frontend systems for a modern cloud platform serving AI, gaming, blockchain, and real-time workloads.

At Nirvana Labs, he extended the cloud API to support a second networking and compute backend and implemented Temporal workflows for VPC provisioning and teardown, VM provisioning, and firewall rules in a new region.

Previously, he worked at Notabene (YC S20), where he joined as its second engineering hire and helped build a Travel Rule API and dashboard used by crypto companies to support regulatory compliance.

Before that, he worked at Banco do Brasil across backend, full-stack, API, and junior engineering roles, contributing to Open Finance platforms, API design tooling, RESTful API modernization, OAuth 2.0 security patterns, Angular, Java, Node.js, and PostgreSQL applications.

He also has experience with React Native mobile applications and startup product development.

Bruno speaks Portuguese as a native speaker, English at a highly proficient level, and Italian with good working knowledge.
