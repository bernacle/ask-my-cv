# Case Studies

## Networking And Compute Backend At Nirvana Labs

Bruno extended the Nirvana Labs cloud API to support a second networking and compute backend.

He implemented Temporal workflows for VPC provisioning and teardown, VM provisioning, and firewall rules in a new region, including public IPs, NAT, CIDR allocation, capacity checks, retries, and rollback.

## Enterprise Identity Migration At Nirvana Labs

Bruno led the migration from Auth0 to WorkOS across the Nirvana Labs dashboard and API.

The work enabled enterprise SSO, SCIM directory sync, and SIEM audit logging. It involved security-sensitive identity flows across backend services, product UI, API integration, authentication flows, and production deployment.

## Crypto Compliance Platform At Notabene

Bruno joined Notabene (YC S20) as its second engineering hire and helped build a Travel Rule API and dashboard used by crypto companies to support regulatory compliance.

He built transaction decision rules, exchange data-collection widgets, internal tools, and customer-facing workflows for regulated crypto transactions.

He also contributed to Terraform infrastructure provisioning and production service operations.

## Kafka And Microservices Evolution At Notabene

Bruno helped evolve Notabene's platform from a monorepo toward microservices using Kafka.

The goal was to improve service boundaries, scalability, and availability.

## Open Finance Tooling At Banco do Brasil

As Lead Backend Engineer at Banco do Brasil, Bruno scoped and built a Node.js and PostgreSQL application to automate API design workflows for the bank's Open Finance initiative.

The application reduced manual API design work for a compact team of developers and one project manager in a highly regulated banking environment.

## Developer Platform Leadership At Banco do Brasil

As Lead Full Stack Engineer at Banco do Brasil, Bruno led a team of developers building an Open Finance developer platform for external developers and bank API services.

The platform used Angular and Java and focused on API discovery, developer experience, and internal service delivery.
