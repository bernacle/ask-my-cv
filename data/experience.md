# Bruno Simplicio Experience

## Current Role: Nirvana Labs

Bruno is a Senior Software Engineer at Nirvana Labs, working remotely since 2025.

He builds backend and frontend systems for a modern cloud platform serving AI, gaming, blockchain, and real-time workloads. His work includes Go API resources such as Projects, Organizations, Memberships, and role-based access patterns for multi-tenant customer accounts.

He also built the customer dashboard and marketing site from the ground up, owning frontend architecture, API integration, authentication flows, and production deployment.

He led the migration from Auth0 to WorkOS across the dashboard and API, enabling enterprise SSO, SCIM directory sync, and SIEM audit logging.

## Crypto Compliance And Travel Rule: Notabene

Bruno worked as a Senior Software Engineer at Notabene from 2021 to 2025.

He joined as one of the first engineers and helped build a Travel Rule API and dashboard used by crypto companies to support regulatory compliance.

His work included transaction decision rules, exchange data-collection widgets, internal tools, and customer-facing workflows for regulated crypto transactions.

He contributed to infrastructure provisioning with Terraform and production service operations across backend, frontend, and platform responsibilities.

He helped evolve the platform from a monorepo toward microservices using Kafka to improve service boundaries, scalability, and availability.

He also supported startup growth through hiring, interviewing, onboarding, and mentoring new engineers.

## Open Finance And Banking: Banco do Brasil

Bruno worked in multiple engineering roles at Banco do Brasil from 2015 to 2021.

As Lead Backend Engineer from 2020 to 2021, he scoped and built a Node.js and PostgreSQL application to automate API design workflows for the bank's Open Finance initiative. The tool reduced manual API design work for a compact team of developers and one project manager.

As Lead Full Stack Engineer from 2018 to 2020, he led a team building an Open Finance developer platform for external developers and bank API services. He built platform features using Angular and Java to improve API discovery, developer experience, and internal service delivery.

As API Software Engineer from 2017 to 2018, he modernized legacy banking services into RESTful APIs using Java and implemented OAuth 2.0 security patterns.

As Junior Software Engineer from 2015 to 2017, he built and maintained AngularJS and Java applications while collaborating with senior engineers on production banking systems.

## Mobile And Startup Experience

In 2020, Bruno worked as a React Native Engineer at Crowdbotics, delivering a mobile app for a medical and aesthetic business. Features included live maps with directions, Square payments, image and PDF uploads, and chat messaging.

From 2019 to 2020, Bruno was Full Stack Engineer and Co-Founder at Combinis, where he launched an internal classified advertisements app for employees of large companies using React Native and Firebase. The app reached 2,000 downloads within one week before the product was discontinued during the pandemic.
