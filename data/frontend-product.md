# Frontend And Product

## Frontend Experience

Bruno has worked professionally with React, Next.js, React Native, Angular, and AngularJS.

At Nirvana Labs, he built the customer dashboard and marketing site from the ground up, including frontend architecture, API integration, authentication flows, and production deployment.

At Notabene, he worked on dashboard features, transaction workflows, policy configuration, customer-facing compliance flows, and embedded widgets.

Earlier in his career, Bruno worked with Angular and AngularJS in banking systems and developer platforms.

## End-To-End Feature Ownership

Bruno is comfortable owning features end-to-end.

He likes understanding the product problem, designing the backend, implementing the API, building the frontend flow, handling edge cases, deploying it, and improving it after feedback.

Even when his main responsibility is backend, he likes understanding the full user experience. That helps him design better APIs and avoid backend decisions that make the product harder to use.

## UX And Product Quality

Bruno sees product quality as part of engineering quality.

A feature is not really done just because the backend works. It also needs to make sense to the user, handle errors well, load at a reasonable speed, and fit the workflow.

He cares about details like validation, empty states, loading states, error messages, and whether the frontend and backend work together cleanly.

## Work Beyond Backend-Only Tasks

At Nirvana Labs, Bruno built both backend and frontend systems, including Go APIs, customer dashboard features, the marketing site, authentication flows, and API integrations.

At Notabene, he worked across backend services, dashboard features, widgets, infrastructure-related work, and integrations.

In personal projects, Bruno built Logfolio, an AI-powered app where users could write daily work logs and generate summaries for performance reviews or tailored cover letters. That project involved frontend, backend, data modeling, and AI usage.
