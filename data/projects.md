# Projects And Product Work

## Nirvana Labs Cloud Platform

Bruno builds backend and frontend systems for a modern cloud platform serving AI, gaming, blockchain, and real-time workloads.

Relevant work includes Go API resources for Projects, Organizations, Memberships, role-based access patterns, customer accounts, customer dashboard development, marketing site development, authentication flows, API integration, production deployment, observability, and security-sensitive identity flows.

## Networking And Compute Provisioning At Nirvana Labs

Bruno extended the cloud API to support a second networking and compute backend.

He implemented Temporal workflows for VPC provisioning and teardown, VM provisioning, and firewall rules in a new region. The work included public IPs, NAT, CIDR allocation, capacity checks, retries, and rollback.

## WorkOS Identity Migration

At Nirvana Labs, Bruno led a migration from Auth0 to WorkOS across the dashboard and API.

The migration enabled enterprise SSO, SCIM directory sync, and SIEM audit logging.

## Notabene Travel Rule Platform

Bruno joined Notabene (YC S20) as its second engineering hire and helped build a Travel Rule API and dashboard used by crypto companies to support regulatory compliance.

Related work included transaction decision rules, exchange data-collection widgets, internal tools, customer-facing workflows, Terraform infrastructure provisioning, and production service operations.

## Kafka Microservices Evolution

At Notabene, Bruno helped evolve the platform from a monorepo toward microservices using Kafka to improve service boundaries, scalability, and availability.

## Banco do Brasil Open Finance API Design Tool

As Lead Backend Engineer at Banco do Brasil, Bruno scoped and built a Node.js and PostgreSQL application to automate API design workflows for the bank's Open Finance initiative.

The tool reduced manual API design work for a compact team of developers and one project manager.

## Banco do Brasil Open Finance Developer Platform

As Lead Full Stack Engineer at Banco do Brasil, Bruno led a team building an Open Finance developer platform for external developers and bank API services.

He built platform features using Angular and Java to improve API discovery, developer experience, and internal service delivery.

## Crowdbotics Mobile App

At Crowdbotics, Bruno delivered a React Native mobile app for a medical and aesthetic business.

The app included live maps with directions, Square payments, image and PDF uploads, and chat messaging.

## Combinis Classified Advertisements App

As Full Stack Engineer and Co-Founder at Combinis, Bruno launched an internal classified advertisements app for employees of large companies using React Native and Firebase.

The app reached 2,000 downloads within one week of release before being discontinued during the pandemic.
